BENJAMIN CRESSIOT — QUARTO WEBSITE V13

This version is based on the validated V12 and includes:
- a fully redesigned Research page with five connected scientific axes;
- consistent V12/V13 visual language and responsive layouts;
- discreet scroll reveal animations;
- removal of references to unpublished manuscripts from the public timeline;
- preservation of the validated home page, ACS Central Science cover and navigation.

TO PREVIEW LOCALLY
1. Open this folder in VS Code.
2. Open a terminal in the folder.
3. Run: quarto preview

TO PUBLISH ON GITHUB PAGES
1. Run: quarto render
2. Commit and push the entire project, including the generated docs folder.
3. In GitHub Pages settings, publish from the /docs folder on the main branch.
